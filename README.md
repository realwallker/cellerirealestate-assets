# cellerirealestate-assets

Public media for cellerirealestate.com, served through jsDelivr so the site does not spend Vercel bandwidth or image-optimization quota.

URL pattern: `https://cdn.jsdelivr.net/gh/realwallker/cellerirealestate-assets@<tag>/<path>`

Photos exist as WebP at 256, 640, 1080, 1600 and 2400 px wide (`<name>-<width>.webp`, never upscaled). Generated by `web/scripts/build-cdn-assets.mjs` in the site project. Publish a new tag for every change so cached files stay immutable.
